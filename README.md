# Modbus-TPM-security
A Python-based bump-in-the-wire security solution, with TPM-based hardware security, aimed at securing legacy TCP-based industrial communication protocols, with a primary focus on Modbus TCP.

## Library/modules requirements
- wolfssl [v5.8.4-stable](https://github.com/wolfSSL/wolfssl/releases/tag/v5.8.4-stable) [C]
- wolfTPM [v3.10.0](https://github.com/wolfSSL/wolfTPM/releases/tag/v3.10.0) [C]
- PyCryptodome [3.21.0](https://pypi.org/project/pycryptodome/3.21.0/) [Python]
